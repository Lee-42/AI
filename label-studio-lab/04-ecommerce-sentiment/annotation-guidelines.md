# 电商评论情绪标注规范

- 项目：`ecommerce-sentiment-v1`
- 规范版本：`1.0`
- 标注对象：每条完整评论表达的整体购物体验
- 标注方式：四选一单标签分类

## 标签定义

| 标签 | 定义 | 示例 |
| --- | --- | --- |
| 正向 | 只包含明确的满意、赞扬或推荐 | “质量很好，还会回购。” |
| 负向 | 只包含明确的不满、问题或否定 | “鞋底开胶了，非常失望。” |
| 混合 | 同时包含明确的正向与负向评价 | “款式好看，但是做工粗糙。” |
| 无法判断 | 没有表达态度、尚未体验、信息不足或内容不可用 | “昨天已经签收。” |

## 判断步骤

```text
阅读全文
  ↓
是否存在明确正向评价？
  ↓
是否存在明确负向评价？
  ↓
正向和负向都有 -> 混合
只有正向 -> 正向
只有负向 -> 负向
两者都没有 -> 无法判断
```

## 边界规则

| 场景 | 规则 |
| --- | --- |
| 商品、包装、物流和客服 | 都计入整体购物体验 |
| 同时褒贬 | 标为混合，不比较两侧哪一方更强 |
| 客观状态 | 没有态度时标为无法判断 |
| 尚未使用 | 缺少体验结论时标为无法判断 |
| 明确弱不满 | “一般般”等表达按负向处理 |
| 反讽 | 根据完整语义和事实结果判断，不只看情绪词字面 |
| 转折句 | 同时保留转折前后的评价，不只看“但是”之后 |
| 乱码、广告或无关内容 | 标为无法判断，并记录为待清洗样本 |

## 禁止做法

- 不得只依赖“好、差、满意”等关键词；
- 不得根据品牌、价格或个人经验补充原文没有的信息；
- 不得把困难样本直接 Skip；
- 不得在没有统一规则的情况下自行增加或合并标签；
- 不得因为某一方面更强，就忽略评论中另一方向的明确评价。

## 分歧处理

遇到无法按当前规则确定的样本时：

1. 记录 `review_id`；
2. 写明争议文本和候选标签；
3. 说明现有规范缺少哪条规则；
4. 统一讨论并更新规范版本；
5. 使用新规则重新检查所有同类样本。

不能通过“少数服从多数”掩盖规范缺口。若分歧来自规则含糊，应先修正规则，再仲裁结果。
