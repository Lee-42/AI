# 图片目标检测标注规范

- 项目：`ecommerce-object-detection-v1`
- 规范版本：`1.0`
- 图片尺寸：640×400
- 标注方式：带类别的水平矩形框
- 目标类别：纸箱、瓶子、杯子

## 类别定义

| 标签 | 定义 | 本案例中的识别特征 |
| --- | --- | --- |
| 纸箱 | 用于包装或运输商品的硬质箱体 | 棕色箱体、封箱胶带、直角外轮廓 |
| 瓶子 | 具有瓶盖、瓶颈或细长容器轮廓的容器 | 窄瓶盖、圆角瓶身 |
| 杯子 | 用于饮用的敞口容器 | 杯口、杯身和把手 |

颜色只是合成图片中的辅助视觉特征，不是类别定义。真实数据不能使用“蓝色一定是瓶子”之类的
规则。

## 矩形框规则

1. 框住目标所有可见部分，包括杯子把手、瓶盖和纸箱胶带覆盖的外轮廓；
2. 矩形框尽量紧贴目标最上、最下、最左、最右的可见边界；
3. 不要为了追求紧贴而切掉目标边缘，也不要包含大块背景或阴影；
4. 每个独立目标使用一个框，不把相邻的两个物体合并成一个框；
5. 阴影、桌面、地面和背景线不是目标，不需要标注；
6. 标签必须与框内目标一致，复制框后也要重新检查标签。

## 特殊边界

| 场景 | 本案例规则 |
| --- | --- |
| 图片边缘裁切目标 | 只框可见部分，不推测图片外的完整形状 |
| 目标被其他物体遮挡 | 框可见部分；若仍可辨认则继续标注 |
| 杯子把手 | 属于杯子，必须纳入同一个框 |
| 瓶盖 | 属于瓶子，必须纳入同一个框 |
| 物体阴影 | 不属于物体，不纳入框 |
| 极小或无法辨认目标 | 本案例没有；真实项目需规定最小尺寸和忽略条件 |

`scene-003` 左侧纸箱故意被图片边缘裁切。其框的左边界应贴在图片 `x = 0`，不能假设图片外还有
多少不可见箱体。

## 质量检查

提交每张图片前逐项确认：

```text
[ ] 所有目标都已框选
[ ] 没有把背景或阴影当作目标
[ ] 每个框只有一个对象
[ ] 标签类别正确
[ ] 框紧贴可见边界
[ ] 杯子把手和瓶盖没有被切掉
[ ] 贴边目标没有补画不可见区域
```
